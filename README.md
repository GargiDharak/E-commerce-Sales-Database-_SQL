# E-commerce Sales Database

## Overview
This project uses MySQL to organize e-commerce data and generate sales reports. It demonstrates relational database design, SQL querying, and data validation.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Key Features
- Relational database design for customers, products, orders, and payments.
- SQL joins to combine data from multiple tables.
- Aggregate functions to calculate sales metrics.
- Sales reports using GROUP BY and HAVING.
- Data validation and payment reconciliation.

## SQL Concepts Demonstrated
- CREATE TABLE and INSERT
- SELECT, WHERE, and ORDER BY
- INNER JOIN and LEFT JOIN
- GROUP BY and HAVING
- Aggregate functions such as SUM, COUNT, and AVG
- Views for reusable reports

## How to Run
1. Install MySQL and open MySQL Workbench.
2. Open the project SQL scripts.
3. Execute the database creation script first.
4. Load the sample data.
5. Execute the reporting queries.
6. Review the query results.

## Project Status
Personal portfolio project developed for practical SQL learning and database reporting.

## Skills Demonstrated
SQL querying, relational database management, data validation, and reporting.
